# 設定ウインドウとカラーテーマ

参照実装：TeXShop 5.60 の設定パネル（`TSSettingsWindowController`、`TSPrefPaneLayout`）と
テーマ機能（`TSThemeFileStore`、`TSColorSupport`、`TSPreferences-Color`）。
Issue #105（カラーテーマ）と #106（設定ウインドウの再設計）に対応する。

## 設定ウインドウ

システム設定アプリと同じ作りにした。xib は使わず、`Sources/Settings/` の Swift コードで組み立てる。

- 左にサイドバー（検索欄とカテゴリの一覧）、右に選んだカテゴリを表示する。ツールバーに戻る／進む（⌘[ ／ ⌘]）。
- カテゴリは「一般」「出力画像」「変換」「生成後の処理」「エディタ」「キーボード」「テーマ」の7つ
  （TeXShop 6.00と同じく，「キーボード」は「エディタ」の次）。
  アイコンの色は TeXShop の設定パネルの配色から選んだ。
- 各カテゴリの先頭に見出しのカード（アイコン・名前・概要）を置き、設定は名前付きの角丸グループに分ける。
  行は左に名前（必要なら小さな説明）、右に部品。入切はすべてスイッチ（small）、
  チェックボックスは括弧の対応の「対象」だけ。寸法は TeXShop と同じ（行の最小の高さ 38、左右の余白 12、
  子の項目の字下げ 24、グループの角の丸み 12pt〈macOS 26 以降〉／10pt）。
- 従来の「詳細...」ポップオーバー（ページボックス、アニメーション、自動判定の対象、不可視文字の記号）は、
  行やポップアップメニューに展開した。親の設定が切のとき、子の行は使えない状態になる。
- 設定を検索すると、サイドバーが項目ごとの結果（項目名と所属カテゴリ）に変わる。結果を選ぶと、
  そのカテゴリへ移って行を強調する。全角・半角、大文字・小文字、ひらがな・カタカナは区別しない。
- ウインドウはツールバーを統合したスタイルとサイドバーの分割ビューで作るため、macOS 26 以降では
  Liquid Glass のサイドバーとツールバーになる。
- 設定値の保存先は従来どおりプロファイル（`ControllerG.currentProfile()` が部品から作る）。

## カラーテーマ

TeXShop と同じ plist 形式のテーマを `~/Library/Application Support/TeX2img/Themes` に置く。

- 初回に、同梱テーマ（TeXShop 同梱の9種と、従来の既定色の「TeX2img Lite」「TeX2img Dark」）を置く。
  「TeX2img Lite」「TeX2img Dark」は、消えていれば起動時に戻す。
- 同梱テーマの色はTeXShop 6.00と同じ（括弧内の背景，Draculaの括弧，Manteuffelのコマンドなどを読みやすくした）。
  文字として描く色（本文・コメント・コマンド・括弧・出力ウインドウの文字）は，どのテーマでも背景とのコントラストが4.5以上。
  「TeX2img Lite」も同じ基準で，コメントと強調表示の括弧を少し暗くした（更新2）。
  テーマのフォルダの同梱テーマのコピーは，起動時に一度だけ，TeX2imgが入れたときの色のままのキーを新しい色にする
  （利用者が変えた色，名前を変えたコピー，利用者のテーマはそのまま。済んだ更新はdefaultsの`BundledThemeColorsUpdate`）。
  読めないテーマがあれば，次の起動で再び試す。テーマの保存とこの更新はファイルコーディネーションで調整する。
- 同梱テーマのコピーが壊れていれば（プロパティリストの辞書として読めない，フォルダになっている），起動時に
  `~/Library/Application Support/TeX2img/Backups/Themes` へ移し，同梱のテーマで戻す（メッセージは出さない）。
  起動している間は，ファイルを変えず，同梱のテーマの色で描く。利用者のテーマとシンボリックリンクはそのまま。
  同梱のテーマを写せないなど途中で失敗したときは，壊れたファイルをそのまま残し，次の起動で再び試す。
- 「テーマ」で、ライトモード時とダークモード時のテーマを選ぶ（プロファイルのキー `lightTheme`／`darkTheme`）。
- 「テーマの編集」で選んだテーマの色を変えると、すぐにそのテーマのファイルへ書き込む。
  新規テーマは編集中のテーマの複製として作る。同梱テーマは「元の色に戻す…」で元の色に戻せる。
- 「TeXShop から取り込む」には、`~/Library/TeXShop/Themes` のテーマのうち、TeX2img にないものと
  色が違うものを並べる。選ぶとコピーする（同名のテーマがあるときは置き換えを確認する）。
- TeX2img が使う色とテーマのキー：文字 `EditorText`、背景 `EditorBackground`、カーソル
  `EditorInsertionPoint`、選択範囲 `EditorSelection`、背景の点滅 `EditorFlash`、コメント `SyntaxComment`、コマンド `SyntaxCommand`、
  `{ } と $` `SyntaxMarkerCurly`（ない場合は `SyntaxMarker`）、不可視文字 `EditorInvisibleChar`、
  強調表示された括弧 `EditorHighlightBraces`、括弧内の背景 `EditorHighlightContent`、
  出力ウインドウの文字・背景 `ConsoleText`／`ConsoleBackground`，全角英数記号の文字・背景
  `EditorHighlightZenkakuSymbol`／`EditorHighlightZenkakuSymbolBackground`。キーがないテーマでは従来の既定色を使う
  （全角英数記号のキーがないテーマでは，ほかの文字と同じに表示する）。
- カーソルと選択範囲には「システムカラーを使う」がある（TeXShop 6.00と同じ。キーは
  `EditorInsertionPointUsesSystemColor`／`EditorSelectionUsesSystemColor`）。オンの間はシステムの色
  （アクセントカラー・強調表示色。macOS 12・13 ではカーソルは文字の色で，NSTextView の既定と同じ）で描き，テーマの色はファイルに残す。キーがない（または数でない）テーマは，以前と同じ
  見え方として読む（カーソルはオフ，選択範囲はオン）。同梱テーマはカーソルがオフ，選択範囲がオンで，選択範囲の色は
  TeXShop と同じ（TeX2img Lite は #B3D7FF，TeX2img Dark は #264F78）。選択範囲の色のないテーマでチェックを外すと，
  同名の同梱テーマの色，なければそのときのシステムの色を書き込む。「ソース」は「文字・背景・背景の点滅」「カーソル・
  選択範囲」の2行で，チェックボックスはウェルの下に左端をそろえて置く。「元の色に戻す…」は，選択範囲の色と2つのスイッチのうち
  コピーにないものを変えたうちに数えない（以前のコピーにはない）。ほかの色が欠けていれば，以前と同じく元に戻せる。
  「TeXShop から取り込む」の比較では，両方でスイッチがオンの色は，スイッチを切ると使う色で比べる：保存した色，
  なければ同名の同梱テーマの色（選択範囲の色のない以前のコピーと，選択範囲の色を持つ TeXShop の同梱テーマは同じ。
  TeXShop 側で別の色を保存したテーマは取り込める）。
- 色はTeXShop 6.00と同じく1行に3つ並べ，列の位置はグループ間でそろえる。グループの最後の色は，後ろの空いた列も使える。
  列の幅は（最後の色を除く）最も長い色の名前に合わせ，設定の窓の最小幅は，最も狭いサイドバーでも3列が収まる幅にする
  （英語で843pt，日本語で792pt。以前は780pt）。以前の版が覚えた窓の幅がそれより狭ければ広げる。
- 不透明度を使うのは「背景の点滅」と「全角英数記号の背景」だけで，ほかの色は不透明に描き，カラーウェルも
  不透明度を扱わない（TeXShop 5.60と同じ）。
- 移行：以前のプロファイルの色が既定色から変えてあれば、その色で「以前のライトモードの色」
  「以前のダークモードの色」のテーマを作って選ぶ。変えていなければ「TeX2img Lite」「TeX2img Dark」を選ぶ。

## キーボードショートカット

TeXShop 5.60の「設定」→「キーボード」と同じく，メニューのコマンドのショートカットを変更できる（マクロはない）。

- 起動時に，メニュー項目へTeXShopと同じ規則の識別子 `TSShortcut.<アクション>.<タグ>` を付ける。
  AppKitが加える項目とウインドウ一覧の項目は対象外。
- 変更は既定値との差だけを `MenuShortcutOverrides`（ユーザーのdefaults，プロファイルの外）に保存する。
  保存した割り当てがほかのメニューのキーと重なるときは使わず，「使えないショートカット」として示す。
- ショートカットは一覧の行で記録する（TeXShop 6.00と同じく，Xcodeのキー割り当ての方式。変更用のシートはない）。
  選んだ行のショートカットをクリック，ダブルクリック，またはReturnで，その欄がキーを待つ欄になる。
  空いているキーはすぐに割り当てる。ほかのコマンドが使うキーや使えないキーは拒否し，行に黄色の三角を，
  一覧の下の行に理由を出して記録を続ける。一覧の下の行は，ふだんは選んだコマンドのデフォルトのショートカットを示す。
  Escape・Return・Tab・ほかの場所のクリックで記録を終え，Deleteか欄の削除ボタンでショートカットを削除する。
  「すべてデフォルトに戻す」の確認のボタンは破壊的な操作として表示する。
- 「機能で検索」はコマンド名で，「キーで検索」は押したキーで絞り込む。補完キーがTabのとき，Tabは補完用。
  キーで検索している間に，フォーカスがメニューのショートカットの部品の外（設定の検索欄など）に移ると，
  キーでの検索を終える。検索欄の消去ボタンは，検索したキーを忘れて次のキーを待つ。
- コマンド補完キーの設定もこのカテゴリに置く。設定の検索でもメニューのコマンド名を探せる。

## 回帰テスト

リポジトリ直下で実行（画面にウインドウを出さず、利用者のテーマのフォルダにも書き込まない）：

```sh
python3 tests/test_settings_panel.py /tmp/tex2img-settings-images
```

製品の設定ウインドウのコードを ControllerG の代役と組み合わせてビルドし、次を確かめる。
全カテゴリの画像（日英・ライト／ダーク）を指定したフォルダに書き出す。

- カテゴリの順序、見出しのカード、グループの見出し、スイッチの大きさ、括弧のチェックボックス
- 親の設定に従う行の有効・無効
- 検索（全角・半角を区別しない、説明も対象）、戻る／進む
- 同梱テーマの設置、既定テーマの選択、テーマ名の検査、色の読み取り（`SyntaxMarker` への後退、範囲外・不正な値）
- カードのラベルが，既定の幅と最も狭い幅（590pt）で文を欠かさないこと（1行のラベルは文の幅，折り返すラベルは文の高さ）
- 以前のプロファイルの色の移行と、二重に作らないこと
