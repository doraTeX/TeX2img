# 設定ウインドウとカラーテーマ

参照実装：TeXShop 5.60 の設定パネル（`TSSettingsWindowController`、`TSPrefPaneLayout`）と
テーマ機能（`TSThemeFileStore`、`TSColorSupport`、`TSPreferences-Color`）。
Issue #105（カラーテーマ）と #106（設定ウインドウの再設計）に対応する。

## 設定ウインドウ

システム設定アプリと同じ作りにした。xib は使わず、`Sources/Settings/` の Swift コードで組み立てる。

- 左にサイドバー（検索欄とカテゴリの一覧）、右に選んだカテゴリを表示する。ツールバーに戻る／進む（⌘[ ／ ⌘]）。
- カテゴリは「一般」「出力画像」「変換」「生成後の処理」「エディタ」「外観」の6つ。
  アイコンの色は TeXShop の設定パネルの配色から選んだ。
- 各カテゴリの先頭に見出しのカード（アイコン・名前・概要）を置き、設定は名前付きの角丸グループに分ける。
  行は左に名前（必要なら小さな説明）、右に部品。入切はすべてスイッチ（small）、
  チェックボックスは括弧の対応の「対象」だけ。寸法は TeXShop と同じ（行の最小の高さ 38、左右の余白 12、
  子の項目の字下げ 24、グループの角の丸み 12pt〈macOS 26 以降〉／10pt）。
- 従来の「詳細...」ポップオーバー（ページボックス、アニメーション、自動判定の対象、不可視文字の記号）は、
  行やポップアップメニューに展開した。親の設定が切のとき、子の行は使えない状態になる。
- 設定を検索すると、サイドバーが項目ごとの結果（項目名と所属カテゴリ）に変わる。結果を選ぶと、
  そのカテゴリへ移って行を強調する。全角・半角、大文字・小文字、ひらがな・カタカナは区別しない。
- ウインドウはツールバーを統合したスタイルとサイドバーの分割ビューで作るため、macOS 26 以降では
  Liquid Glass のサイドバーとツールバーになる。
- 設定値の保存先は従来どおりプロファイル（`ControllerG.currentProfile()` が部品から作る）。

## カラーテーマ

TeXShop と同じ plist 形式のテーマを `~/Library/Application Support/TeX2img/Themes` に置く。

- 初回に、同梱テーマ（TeXShop 同梱の9種と、従来の既定色の「TeX2img Lite」「TeX2img Dark」）を置く。
  「TeX2img Lite」「TeX2img Dark」は、消えていれば起動時に戻す。
- 「外観」で、ライトモード時とダークモード時のテーマを選ぶ（プロファイルのキー `lightTheme`／`darkTheme`）。
- 「テーマの編集」で選んだテーマの色を変えると、すぐにそのテーマのファイルへ書き込む。
  新規テーマは編集中のテーマの複製として作る。同梱テーマは「元の色に戻す…」で元の色に戻せる。
- 「TeXShop から取り込む」には、`~/Library/TeXShop/Themes` のテーマのうち、TeX2img にないものと
  色が違うものを並べる。選ぶとコピーする（同名のテーマがあるときは置き換えを確認する）。
- TeX2img が使う色とテーマのキー：文字 `EditorText`、背景 `EditorBackground`、カーソル
  `EditorInsertionPoint`、背景の点滅 `EditorFlash`、コメント `SyntaxComment`、コマンド `SyntaxCommand`、
  `{ } と $` `SyntaxMarkerCurly`（ない場合は `SyntaxMarker`）、不可視文字 `EditorInvisibleChar`、
  強調表示された括弧 `EditorHighlightBraces`、括弧内の背景 `EditorHighlightContent`、
  出力ウインドウの文字・背景 `ConsoleText`／`ConsoleBackground`。キーがないテーマでは従来の既定色を使う。
- 移行：以前のプロファイルの色が既定色から変えてあれば、その色で「以前のライトモードの色」
  「以前のダークモードの色」のテーマを作って選ぶ。変えていなければ「TeX2img Lite」「TeX2img Dark」を選ぶ。

## 回帰テスト

リポジトリ直下で実行（画面にウインドウを出さず、利用者のテーマのフォルダにも書き込まない）：

```sh
python3 tests/test_settings_panel.py /tmp/tex2img-settings-images
```

製品の設定ウインドウのコードを ControllerG の代役と組み合わせてビルドし、次を確かめる。
全カテゴリの画像（日英・ライト／ダーク）を指定したフォルダに書き出す。

- カテゴリの順序、見出しのカード、グループの見出し、スイッチの大きさ、括弧のチェックボックス
- 親の設定に従う行の有効・無効
- 検索（全角・半角を区別しない、説明も対象）、戻る／進む
- 同梱テーマの設置、既定テーマの選択、テーマ名の検査、色の読み取り（`SyntaxMarker` への後退、範囲外・不正な値）
- 以前のプロファイルの色の移行と、二重に作らないこと
